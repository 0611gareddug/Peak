# SPIRE

친구들과 함께 산맥 섬의 화산 정상까지 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v0.9 · 산맥 섬)
- 해변에서 화산 정상(약 730m)까지 이어지는 **산맥형 섬**, 4구간: Ⅰ 짠물 해안 → Ⅱ 덩굴 협곡 → Ⅲ 서리 빙하 → Ⅳ 잿불 화산
- 봉우리 여러 개와 능선, 계단식 바위턱(발 디딜 곳), 해안 초원·빙하 설원 같은 넓은 평야
- 지형지물 100여 개: 바다 아치·큰 아치, 크레바스와 그 위 자연 다리·눈다리, 들어갈 수 있는 동굴(안에 좋은 보급), 협곡을 막은 바위 굴, 통나무 다리, 버섯 선반이 달린 거대 나무, 바다 기둥·얼음 기둥·현무암 기둥 점프 코스, 용암 골
- 구간마다 화톳불 캠프(체크포인트), 화산 분화구 가장자리 정상 깃발 엔딩
- 날씨: 비(젖음), 눈보라(추위·시야), 화산재 / 위험: 가시덤불(독), 열기 구멍·용암(화상)
- 상태이상(배고픔·추위·독·졸음·화상·젖음), 낮과 밤, 아이템 26종, 보급 상자 80여 개
- 달리기는 스태미나를 쓰지 않음 (점프·등반·도약만 사용)
- 멀티플레이: 방 코드로 최대 4인, 끌어올리기, 부활, 로프·닻 못 공유, 채팅·이모트·핑
- 직접 그린 SVG 아이콘·HUD (종이 스티커 + 잉크 테두리), PC와 모바일(터치) 지원, 한국어 / English

## 조작 (PC)
WASD 이동 · 마우스 시점 · 좌클릭(꾹) 잡기 · Space 점프/도약 · Shift 달리기 · E 상호작용 · 우클릭/F 아이템 · 1~5 배낭 칸 · G 버리기 · T 채팅 · B 이모트 · Q 핑

모바일: 배낭 칸 탭으로 선택, 길게 누르면 버리기
