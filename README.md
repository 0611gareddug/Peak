# SPIRE

친구들과 함께 섬의 봉우리를 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v0.7 · 3단계 생존)
- Ⅰ 짠물 절벽 구간 (0 → 251m, 화톳불 캠프)
- 벽 잡기 등반, 스태미나, 낙하 부상
- 테라스 6층, 절벽에 파인 나선형 흙길, 동굴, 협곡, 폭포, 고도별 바이옴 4개
- 상태이상: 배고픔 · 추위 · 독 · 졸음 · 젖음 (스태미나 바를 차지)
- 낮과 밤 (밤에는 춥고 졸림, 불가·동료 곁에서 회복)
- 아이템 26종: 음식·열매·버섯·장비(로프, 닻 못, 헤드랜턴)·회복·유물
- 보급 상자 32개, 열매 덤불과 버섯 줍기, 배낭 무게
- 탐험가 특기 (선봉대 / 의무병 / 짐꾼)
- 멀티플레이: 방 코드로 최대 4인, 끌어올리기, 부활, 로프·닻 못 공유, 채팅·이모트·핑
- PC와 모바일(터치) 지원, 한국어 / English
