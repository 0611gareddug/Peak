# SPIRE

친구들과 함께 산맥 섬의 화산 정상까지 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v1.0 · 세계수 섬)
- 걷기 25 · 점프맵 45 · 등반 30 비율로 다시 만든 산맥 섬: 해변 → 꽃 초원·호수 → 해안 절벽 → 밀림·거대 버섯 숲 → 폭포 절벽 → **세계수** → 빙하 설원 → 화산 정상(약 494m)
- **세계수**(약 140m): 뿌리 사이 길, 줄기를 감는 나선 길(걷기) + 버섯 선반(점프) + 줄기 등반, 잎 지붕 데크 위 화톳불, 큰 가지로 빙하까지 건너감
- 점프 코스: 해안 절벽 앞 떠 있는 바위섬 나선 탑, 거대 버섯 숲(W자 코스), 호수 위 바위섬, 큰 크레바스 얼음섬, 얼음벽 나선, 현무암 탑, 분화구 흑요석 섬, 유적 돌기둥
- 호수(수영 가능)·강·폭포 2곳, 얼어붙은 호수, 흙길·화산 돌계단 길, 옛 원정대 유적과 석상, 빛나는 버섯
- 6m 아래 낙하는 피해 없음, 달리기 스태미나 소모 없음, 상태이상 완화
- 모바일 화면 배치 편집: 버튼·스태미나 HUD·배낭 칸 위치/크기, 버튼 투명도
- 멀티플레이 최대 4인, PC·모바일, 한국어 / English

## 조작 (PC)
WASD 이동 · 마우스 시점 · 좌클릭(꾹) 잡기 · Space 점프/도약 · Shift 달리기 · E 상호작용 · 우클릭/F 아이템 · 1~5 배낭 칸 · G 버리기 · T 채팅 · B 이모트 · Q 핑

모바일: 배낭 칸 탭으로 선택, 길게 누르면 버리기
