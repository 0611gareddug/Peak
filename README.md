# SPIRE

친구들과 함께 섬의 봉우리를 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v0.8 · 4단계 월드)
- 1000m 봉우리, 4구간: Ⅰ 짠물 절벽 → Ⅱ 덩굴 숲 → Ⅲ 서리 능선 → Ⅳ 잿불 정상
- 큰 산 주변의 바위 탑 50여 개 (탑 사이 좁은 협곡, 탑 꼭대기 발판), 크레바스, 동굴
- 구간마다 화톳불 캠프(체크포인트), 정상 깃발 꽂기 엔딩
- 구간 특성: 덩굴 벽(빨리 오름), 얼음벽(얼음 송곳 없으면 미끄러짐), 가시덤불(독), 열기 구멍(화상)
- 날씨: 비(젖음), 눈보라(추위·시야), 화산재
- 상태이상(배고픔·추위·독·졸음·화상·젖음), 낮과 밤, 아이템 26종, 보급 상자 100여 개
- 멀티플레이: 방 코드로 최대 4인, 끌어올리기, 부활, 로프·닻 못 공유, 채팅·이모트·핑
- PC와 모바일(터치) 지원, 한국어 / English

## 조작 (PC)
WASD 이동 · 마우스 시점 · 좌클릭(꾹) 잡기 · Space 점프/도약 · Shift 달리기 · E 상호작용 · 우클릭/F 아이템 · 1~5 배낭 칸 · T 채팅 · B 이모트 · Q 핑
