# SPIRE

친구들과 함께 산맥 섬의 화산 정상까지 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v1.2 · 절벽의 산)
- 걷기는 거의 없이, 해변에서 바로 절벽이 시작되는 거대한 산: 바위턱(8m마다 쉬는 턱)·침니·오버행이 이어지는 절벽 → 화톳불(170m) → 밀림 절벽·**세계수**(줄기 등반, 가지 쉼터, 꼭대기 가지 다리) → 빙하 얼음 절벽(541m) → 화산 바위 띠 4겹 → 분화구 정상(727m)
- 절벽마다 **사다리**(빠르고 덜 지침)와 **고정 밧줄**, 절벽에 박힌 **나무 발판**, 골짜기를 건너는 **출렁다리**
- 보너스 길: 해변 디딤돌, 바위 기둥, 거대 버섯 지름길, 얼음섬, 현무암 탑
- 맵 뚫림 방지: 빠른 이동을 잘게 나눠 충돌 처리, 지형 속에 갇히면 위로 꺼냄, 카메라가 벽 속을 비추지 않게, 섬 밖 보이지 않는 벽
- 예전(v0.8) 손목 장비 HUD와 툰 화풍, 모바일 화면 배치 편집, 멀티 최대 4인, 한국어 / English
