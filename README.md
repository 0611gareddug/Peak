# SPIRE

친구들과 함께 산맥 섬의 화산 정상까지 오르는 협동 등반 서바이벌 웹게임 (1~4인).

**플레이:** https://0611gareddug.github.io/Peak/

## 지금 들어 있는 것 (v1.1 · 등반 중심)
- 등반 70 · 점프 15 · 걷기 15: 구간마다 높은 절벽(30~140m)과 2~2.5m 폭의 쉬는 바위턱, 좁은 틈(침니), 비스듬한 오버행, 화산 바위 띠 절벽
- 해변 → 해안 절벽 2개(화톳불 101m) → 밀림 절벽·폭포 절벽 → **세계수**(줄기 등반 + 가지 쉼터, 데크 화톳불 363m) → 빙하 얼음벽 2개(474m) → 화산 바위 띠 → 분화구 정상(643m)
- 점프 코스는 지름길·보너스로 축소: 거대 버섯 지름길, 큰 크레바스 얼음섬, 호수 위 바위섬, 유적 돌기둥, 현무암 탑
- 등반 스태미나 소모 완화, 턱 아래에서 막히면 자동으로 올라서기
- 차분한 화풍: 부드러운 명암, 얇은 외곽선, 낮춘 채도, 반투명 UI
- 호수(수영)·강·폭포, 흙길·화산 돌계단, 유적과 석상, 모바일 화면 배치 편집, 멀티 최대 4인, 한국어 / English
